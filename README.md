# MyNest

Repositório para o projeto MyNest. O projeto consiste em um aplicativo móvel para auxiliar em problemas rotineiros em casa. O software possui as seguintes features:
- Centralizador de Senhas;
- Controle de Mensalidades 

## Estrutura do Projeto

```
lib/
├── main.dart          # Inicialização do Projeto
├── models/            # Modelos de dados
├── screens/           # Telas/páginas do app 
├── widgets/           # Widgets para reutilizar
├── services/          # Camada de serviço para aplicar as regras de negócio
├── providers/         # Gerenciamento de estado
├── utils/             # Funções utilitárias e helpers
└── routes/            # Definição e gerenciamento de rotas de navegação
```
